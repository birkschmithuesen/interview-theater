# Form: stumme Szene

Kein Wort. Die ganze Szene besteht aus Regieanweisungen -- und genau deshalb
muss jede einzelne spielbar sein.

1. **Nur Klammern.** Keine Repliken, keine Namen mit Doppelpunkt, kein
   Erzaehltext. Jede Zeile ist eine Anweisung in runden Klammern.
2. **Die Handlung entscheidet sich an Gegenstaenden.** Ein Koffer, eine Tuer,
   eine Tasse, ein Handy. Was passiert, passiert an einem Ding, das jemand
   in die Hand nimmt, hinstellt, nicht hergibt.
3. **Keine Innensicht.** `(traurig)`, `(zoegert innerlich)`, `(denkt an
   frueher)` sind nicht spielbar. `(nimmt den Mantel nicht ab)`,
   `(stellt die Tasse zurueck)`, `(wartet)` schon.
4. **Zeit ist ein Mittel.** `(Wartet. Laenger.)` und `(Noch einmal, langsamer)`
   sind Anweisungen, keine Verlegenheit. Eine Wiederholung, die beim zweiten
   Mal laenger dauert, traegt eine ganze Szene.
5. **Wiederhol woertlich.** Ein wiederkehrender Vorgang steht beim zweiten
   und dritten Mal buchstabengleich da.
6. **Hoechstens eine Handlung je Zeile.** Zwei Dinge in einer Klammer sind auf
   der Probe eine Diskussion.
7. **Am Ende ist etwas anders** -- sichtbar, an einem Gegenstand oder an
   einer Position im Raum. Ohne Wort und ohne Erklaerung.

## Ausgabeform

Nur Klammerzeilen, eine Handlung je Zeile. Wer handelt, steht in der Klammer:

```
(Schulhof, frueher Morgen. <FIGUR A> steht am Zaun, die Jacke noch zu.)
(<FIGUR B> kommt dazu, bleibt zwei Schritte entfernt stehen.)
(<FIGUR A> dreht sich weg.)
(Wartet. Laenger.)
```
