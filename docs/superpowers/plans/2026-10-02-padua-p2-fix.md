### M1 -- Die bindende Zahl steht im Nutzertext heute schon, aber nur mit aktivem Laengen-Profil

`laengen.py:358-365` traegt `SATZ_BINDUNG = "Genau {anzahl} Abschnitte, in
dieser Reihenfolge, mit diesen Laengen."` (englisch `en/texte.toml:1544`), und
`laengen.block_prosa` (`laengen.py:397-413`) haengt sie an **jeden**
Budget-Block. `kurzgeschichte.baue_nutzertext` setzt diesen Block, sobald
`eintraege` nicht leer sind (`kurzgeschichte.py:349-350`), und
`kurzgeschichte.schreibe` holt sie immer (`budget_eintraege`, Z. 404).

**Folge fuer die Umsetzung:** eine zweite bindende Zeile im Auftrag waere bei
aktivem Profil eine **Doppelnennung** -- genau das, was „ein Fakt, eine
Stelle" verbietet. Die neue Auftragszeile steht deshalb **nur, wenn der
Laengen-Block sie nicht schon traegt** (Task 7). Die Zahl ist damit in
**jedem** Prosa-Prompt mit geplanten Szenen gebunden, in genau einem Block.

*Verworfene Alternative:* `SATZ_BINDUNG` aus `block_prosa` herausnehmen und
die Bindung immer in den Auftrag legen. Waere eine Stelle statt zwei
Codepfade, kostet aber eine Aenderung an Karte R
(`laengen.block_prosa`, `tests/test_laengen_prosa.py:165`), loescht eine
getestete Konstante und beruehrt `texte-vor-sprache-a1.txt`. **Der Reviewer
kann sie bestellen**; der Plan nimmt den kleineren Eingriff.

### M2 -- Restspannung 5 ist im Nutzertext bereits abgedeckt; die Karte hat nur die Regie-Notiz angesehen

`nachpass.nach_geschichte` (`nachpass.py:288-376`) bricht ohne aktives

`eintraege=budgets` an `kurzgeschichte.hole_text` (Z. 350) -- also steht

Jede andere Abweichung ist ein Befund und bricht ab: ein Massstab, der sich
unkontrolliert neu schreibt, prueft nichts mehr."""
import pathlib
import re
import sys

from interview_theater import anweisungen
from scripts import prompt_schnappschuss

ERLAUBT = {
    "prompt system",
    "anweisungen.system(phase=None)",
    *(f"anweisungen.system(phase={n})" for n in range(1, 8)),
}
ZEILE = re.compile(r"^(\S+)\s+(\d+)\s+(.*)$")


def lies(text):
    paare = []
    for zeile in text.splitlines():
        pruef, laenge, name = ZEILE.match(zeile).groups()
        paare.append((name, f"{pruef}  {int(laenge):7d}"))
    return paare


datei = pathlib.Path(sys.argv[1])
anweisungen._CACHE.clear()
jetzt = dict(lies(prompt_schnappschuss.fingerabdruck()))
alt = lies(datei.read_text(encoding="utf-8"))

fehler = []
neu_zeilen = []
gehoben = []
for name, wert in alt:
    aktuell = jetzt.get(name)
    if aktuell is None:
        fehler.append(f"verschwunden: {name}")
        neu_zeilen.append(f"{wert}  {name}")
        continue
    if aktuell != wert:
        if name not in ERLAUBT:
            fehler.append(f"unerwartet geaendert: {name}")
        else:
            gehoben.append(name)
        neu_zeilen.append(f"{aktuell}  {name}")
    else:
        neu_zeilen.append(f"{wert}  {name}")

print("gehoben:", len(gehoben))
for name in gehoben:
    print("  ", name)
if fehler:
    print("FEHLER:")
    for f in fehler:
        print("  ", f)
    sys.exit(1)
if sorted(gehoben) != sorted(ERLAUBT):
    print("FEHLER: nicht alle erwarteten Abschnitte haben sich geaendert:",
          sorted(set(ERLAUBT) - set(gehoben)))
    sys.exit(1)
datei.write_text("\n".join(neu_zeilen) + "\n", encoding="utf-8")
print("geschrieben:", datei)
